# Linux Security

This category contains command-line projects involving software management, cryptography, users, groups, file permissions, access control, and secure system administration.

## Skills Demonstrated

- Linux command line
- Software and package management
- Cryptographic file operations
- Bash pipes and text processing
- Safe use of elevated privileges
- File and directory permissions
- User and group management
- Least-privilege access
- Technical documentation

## Projects

| Project | Description | Commands/Tools |
|---|---|---|
| [Linux Software Management with APT](linux-software-management/) | Installed, removed, reinstalled, and verified the Suricata and tcpdump network-security applications in a Debian-based Linux environment. | Bash, APT, sudo, Suricata, tcpdump |
| [Linux Cryptography and File Decryption](linux-cryptography-file-decryption/) | Located hidden instructions, decoded a Caesar cipher, and recovered an AES-256-CBC encrypted file using OpenSSL. | Bash, ls, cat, tr, pipes, OpenSSL, AES, PBKDF2 |

## Project Documentation Standard

Each project documents the security problem, commands used, results, verification steps, security relevance, and lessons learned.
