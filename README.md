# Cybersecurity Lab Portfolio

Welcome to my hands-on cybersecurity portfolio. This repository documents practical labs and projects completed as I develop the technical, analytical, and documentation skills needed for a cybersecurity analyst role.

| Category | Skills Demonstrated |
|---|---|
| [Security Audits and Risk Assessments](./01-security-audits-and-risk-assessments/) | Security controls, risk identification, compliance, remediation |
| [Incident Response](./02-incident-response/) | Incident analysis, documentation, containment, recovery |
| [Linux Security](./03-linux-security/) | File permissions, users, groups, command-line administration |
| [SQL Investigations](./04-sql-investigations/) | Querying, filtering, log analysis, investigation |
| [Network Traffic Analysis](./05-network-traffic-analysis/) | Protocols, packet analysis, traffic patterns, threat detection |

| [Security Playbooks](./08-security-playbooks/) | Response procedures, escalation, communication, repeatable workflows |

## About This Portfolio

Each project will explain:

- The scenario or security problem
- My role and objective
- The tools and methods I used
- My analysis and findings
- My recommendations or solution
- What I learned

> All scenarios use fictional or sanitized information. No passwords, API keys, private network information, or sensitive client data are included.
