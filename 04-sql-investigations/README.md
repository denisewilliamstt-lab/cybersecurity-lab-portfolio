# SQL Investigations

This category contains SQL projects that use filtering, joins, and logical operators to investigate security events, correlate records, and identify security gaps.

## Skills Demonstrated

- Relational database analysis
- SQL filtering and sorting
- `AND`, `OR`, and `NOT` operators
- `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`
- Table aliases and qualified column names
- Identification of unmatched records with `NULL`
- Security log and asset investigation
